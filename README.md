# 🎓 Online Examination System

> A modern, secure, and user-friendly web application for conducting online examinations efficiently.

---

## 🚀 Project Overview

The **Online Examination System** is designed to simplify the process of creating, managing, and attending online exams. It provides an interactive platform for **students**, **teachers**, and **administrators** with features like authentication, exam scheduling, result management, and responsive UI support.

This project is built using **React + TypeScript + Vite**, making it fast, scalable, and easy to maintain.

---

## ✨ Features

* 🔐 **User Authentication** (Login / Registration)
* 📝 **Create & Manage Exams**
* ⏱️ **Real-time Exam Timer**
* 📊 **Automatic Result Evaluation**
* 📱 **Responsive Design**
* 🎨 **Modern UI with Tailwind CSS**
* ⚡ **Fast Development with Vite**
* 📂 **Easy Project Structure**

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://https://github.com/AyanSaifi01/Online_Examination_System_
```

### 2️⃣ Navigate to the project folder

```bash
cd Online_Examination_System
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server

```bash
npm run dev
```

The application will run at:

```bash
http://localhost:5173
```
